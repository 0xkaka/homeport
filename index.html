1粘贴住宅代理信息

没有的话先买一条：便宜住宅 IP 购买教程

服务商后台给你的那一串，直接整串粘进来就行。支持这些格式：
地址:端口:用户名:密码　用户名:密码@地址:端口　http://用户名:密码@地址:端口

⚠️ 地址要填后台的 Proxy Address / 代理地址（比如 Webshare 是 p.webshare.io）， 不是 “Assigned IP / 出口 IP”。出口 IP 只是最后网站看到的 IP，用来核对结果。

Shadowrocket（小火箭）

      
顺序很重要：先装模块，再加节点。整个过程中，首页选中的节点一直保持你平时用的机场节点，不要点选 HP_Home。
        HP_Home 只给规则用，选中它会让所有流量都走住宅代理，GitHub 等网站可能打不开。


      
第一步：装规则模块（趁现在网络正常）

        首页先确认能正常上网 → 底部 配置 → 模块 → 右上角 ＋，粘贴下面链接 → 下载。

      

      

        
你改过第 2 步的网站选择，在线模块里是默认规则。装好模块后还要替换成你的版本：
          在 模块 列表里点开 homeport → 编辑 → 全选删掉 → 粘贴下面复制的内容 → 保存。
          以后别点这个模块的“更新”，否则会变回默认。

第三步：设跳板：点 HP_Home 右边 ⓘ → 代理通过 → 选一个台湾/日本/新加坡/美国/韩国节点 → 保存。

        设好后节点下面会显示类似 HTTP / 跳板名 > SHADOWSOCKS，意思是“HTTP 住宅代理，经由某个 Shadowsocks 跳板”，这是正常的。
        HP_Home 测速显示“超时”不一定代表不能用，以第 4 步打开 ipv4.webshare.io 的结果为准。


      
第四步：切到配置模式：首页 全局路由 选 配置；选中的节点是机场节点；打开开关。

        这样只有 Claude、Google 等走住宅出口，其他网站照常走机场。
